# e-Barangay Barahan: Digital Reporting System

Barangay: Barahan, Santa Cruz, Occidental Mindoro - 6,939 residents

1. Problem Location: Barangay Barahan, Sta. Cruz, Occ. Mindoro
2. Problem Description: Residents struggle to report damaged roads, flooding, garbage. Need to go personally to Barangay Hall far for some puroks. No fast way to report fire incidents. Announcements via megaphone get missed.
3. Affected Users: 6,939 residents, Barangay Officials, Senior Citizens
4. Current Process: Manual logbook at hall, no photo, no tracking.
5. Proposed Solution: Web app for reporting with photo + location + announcement module + status tracking (Pending/In Progress/Resolved).
